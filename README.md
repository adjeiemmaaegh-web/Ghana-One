# Ghana One — unified consumer and business prototype

A standalone, **visual-only** prototype concept for one Ghana-focused application with one account and two experiences:

- **Consumer:** discover products and services, describe a need, compare options, and send sample requests.
- **Business:** view fictional products and orders, change illustrative stock, and switch between shopper and merchant perspectives.
- **Shared identity concept:** one person can shop and run a business; manager/staff roles are invitation-based in the proposed design.

## Source transfer

The independent prototype is intended to come from the **newly authored unified consumer/business preview** previously prepared for review. It must be made self-contained and rebranded *before* being added here. Do **not** copy the original Hoo project, its assets, backend, authentication, or any TallyBook code.

**Privacy checkpoint:** This repository was initially created as public. The prototype source will not be transferred while it is public; change the GitHub repository visibility to **private** first.

## Scope

This is a fictional UI/UX demonstration, **not** a real payment, authentication, chat, or inventory service. Sample orders, stock changes, and customer data remain local to the browser and must be labeled as simulations.

## Planned demo walkthrough

1. Open Ghana One and select a consumer experience.
2. Browse sample local products or describe a shopping need.
3. Compare illustrative offers and create a sample order.
4. Switch to the business workspace under the same fictional identity.
5. Change illustrative stock, then return to the consumer view and observe the update.

## Independence

This project must stay separate from the Hoo and TallyBook GitHub repositories. Their existing branches, pull requests, main branches, and deployments must remain untouched.
